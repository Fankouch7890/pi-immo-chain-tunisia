# Pi Immo Chain Tunisia 🇹🇳

**Pi Immo Chain Tunisia** هي أول منصة عقارية لا مركزية موثقة بلغة العقود الذكية على شبكة **Pi Network** لشراء وبيع واستئجار العقارات في جميع الولايات التونسية بـ Pi.

---

## 🌟 المميزات (Features)

1. **عرض العقارات في تونس**: استعراض الفيلات، الشقق، الأراضي المجهزة، والمحلات التجارية في سوسة، تونس، الحمامات، صفاقس، المنستير وغيرها.
2. **تصفية وبحث ذكي**: تصفية حسب الولاية/المدينة، نوع العقار، والبحث المباشر.
3. **محاكاة محفظة Pi Network**: ربط المحفظة واستعراض الرصيد وتوقيع صفقات الشراء العقارية.
4. **سجل الملكية الشفاف (Blockchain Ledger)**: توثيق وتأكيد العقود برقم هاش فريد غير قابل للتزوير.
5. **REST API متكامل**: خادم Express يوفر واجهات برمجية لربط البيانات وإدارة الصفقات.

## 🚀 كيفية التشغيل (How to Run)

### المتطلبات الأساسية
* Node.js (الإصدار 18 أو أحدث)
* npm

### التثبيت
```bash
npm install
```

### تشغيل الخادم المحلي
```bash
npm start
```
سيكون التطبيق متاحاً على: [http://localhost:3000](http://localhost:3000)

### تشغيل الاختبارات
```bash
npm test
```

## 🔌 مسارات API (API Endpoints)

* `GET /api/properties`: جلب كافة العقارات المدرجة في تونس.
* `GET /api/properties/:id`: جلب بيانات عقار محدد عبر المعرف.
* `GET /api/blockchain/ledger`: استعراض سجل الصفقات الموثقة بالبلوكشين.
* `POST /api/pi/pay`: تنفيذ وتأكيد صفقة شراء عقار بواسطة عملة Pi.
* `GET /api/health`: التحقق من سلامة وصحة تشغيل الخادم.
